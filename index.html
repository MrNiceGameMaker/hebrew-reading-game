טולי טאון

לחוויה הטובה ביותר בטלפון ובטאבלט, מומלץ להתקין את המשחק למסך הבית.

מתקין…

כשהאייקון של טולי טאון מופיע במסך הבית, פתחו ממנו את המשחק וסגרו את הלשונית הזו.

פתח את טולי טאון

החשבון שלי

בחשבון חדש בחרו שם משתמש שאינו השם המלא של הילד, ושמרו את שם המשתמש והסיסמה.

להתחיל מחדש במכשיר הזה?

השמירות המקומיות והכניסה לחשבון יימחקו מהמכשיר. משחקים שכבר סונכרנו לענן יהיו זמינים כשתתחברו שוב.

לפני האיפוס, סגרו עותקים אחרים של טולי טאון שפתוחים במכשיר.

פיילוט טולי טאון

בהסכמת הורה, דוח הפיילוט כולל קוד משפחה, ביקורים, זמן פעיל ושלב אחרון במשחק. אפשר להפסיק את השיתוף בכל עת.

קוד המשפחה

כדי לפתוח את הדוח, התחברו בחשבון מנהל הפיילוט ואמתו את כתובת הדוא״ל.
